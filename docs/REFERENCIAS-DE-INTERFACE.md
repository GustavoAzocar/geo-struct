# Referências de interface

Consulta em 17/11/2026. Implementação própria, sem reprodução de código, marcas ou telas comerciais.

| Referência                                                                                                       | Prática observada                                                                                                                               | Aplicação no GeoStruct                                                                                   |
| ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| [Slide2 — Quick Start](https://www.rocscience.com/help/slide2/tutorials/tutorials-overview/quick-start-tutorial) | Modelar contorno, atribuir materiais, configurar análise, inspecionar resultados e produzir relatório; entrada por coordenadas, grade e captura | Comandos organizados pelo trabalho, geometria central, propriedades e tabela X/Z                         |
| [Slide2 — especificações](https://www.rocscience.com/help/slide2/overview/technical-specifications)              | Seções 2D, materiais, cargas, água, superfícies e dados por fatia                                                                               | Organização extensível para futuras análises; recursos não implementados não exibem resultados simulados |
| [GEO5 — Interface / Slope Stability](https://www.finesoftware.eu/help/geo5/en/interface-01/)                     | Geometria geotécnica por pontos e interfaces                                                                                                    | Edição gráfica acompanhada de entrada precisa por coordenadas                                            |
| [GEO5 — Water](https://www.finesoftware.eu/help/geo5/en/water-14/)                                               | Definição explícita das condições de água                                                                                                       | Linha piezométrica nomeada, distinguida de fluxo numérico                                                |
| [ConsoloStruct](https://github.com/ricardocorsini/consolo-struct)                                                | Ribbon, árvore, abas, propriedades, temas, domínio independente e Tauri                                                                         | Estrutura familiar ao ecossistema OpenStruct                                                             |
| [ArmaduraStruct](https://github.com/ricardocorsini/armadura-struct)                                              | Interação CAD, seleção, histórico e arquivos locais                                                                                             | Captura, pan/zoom, desfazer por operação e proteção de edição                                            |

A aparência mantém a paleta terrosa existente, com o nome GeoStruct na interface e os ícones padrão do Tauri no aplicativo nativo. A arte personalizada será incorporada posteriormente. Não houve cópia de componentes de repositórios com licenças diferentes. Dados de cálculo de terceiros não foram incorporados.
